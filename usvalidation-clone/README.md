# U.S. Validation Services — website recreation

A responsive front-end recreation inspired by the public U.S. Validation Services website at https://usvalidation.com/.

## Included
- Responsive landing page for pharmaceutical and GMP validation consulting
- Service overview cards
- Risk-based validation approach section
- Knowledge-base preview
- Contact CTA and responsive navigation

## Run locally
Open `index.html` in a browser. No build step is required.

This is an independent front-end recreation for demonstration purposes. It is not affiliated with or endorsed by U.S. Validation Services. Contact forms and service links are demo interactions and must be connected to real services before production use.
